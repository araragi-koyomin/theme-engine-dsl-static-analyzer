# 主题引擎DSL静态分析工具-产品需求文档

## 1. 产品概述

### 1.1 产品名称
主题引擎DSL静态分析工具

### 1.2 产品类型
IntelliJ IDEA插件

### 1.3 产品目标
为主题开发者提供DSL文件的语法实时检测与自动修正（Quick Fix）功能，提升在IDEA中编辑DSL文件的效率与准确性。

### 1.4 目标用户
- 主题开发者
- 需要实时语法语义检查的UI开发人员

### 1.5 用户痛点
- DSL文件缺乏IDE级别的实时语法检查，错误只能运行时发现
- 语法错误难以定位，无上下文提示
- 修正错误需手动查阅文档，效率低
- 缺乏项目级别的批量质量检查手段

## 2. 功能需求

### 2.1 核心功能：实时语法与语义检测

#### 2.1.1 文件识别功能
- 自动识别DSL文件并启用相应的检查规则
- 仅对DSL文件生效，不影响其他XML文件的正常编辑体验

#### 2.1.2 实时语法错误检测
- 对DSL文件进行实时语法分析
- 检测内容：
  - XML标签未闭合
  - 标签嵌套错误
  - 属性引号缺失

#### 2.1.3 语义/规则错误检测
- 基于DSL规范对文件进行语义和规则检查
- 检测内容：
  - 未知组件（未在规范中定义）
  - 组件不支持当前应用位置
  - 必填属性缺失
  - 未知属性
  - 属性类型不匹配
  - 单位不匹配
  - 枚举值不合法
  - 数值范围越界
  - 父子结构不合法

#### 2.1.4 Quick Fix
- 对每种可检测的错误类型提供自动修复建议
- 支持的修复类型：
  - 补闭合标签、补属性引号、删除多余结束标签
  - 插入必填属性占位值或默认值
  - 数字/布尔/路径格式归一化
  - 建议替换为最接近的合法组件名（需确认）
  - 替换为别名属性、删除属性、转为通用属性（需确认）
  - 单位换算或删除错误单位（需确认）
  - 替换为最接近合法枚举值（需确认）
  - clamp到合法范围（需确认）

#### 2.1.5 规则来源说明
- 每个诊断问题和Quick Fix都附带明确的规则来源和文档链接
- 用户可追溯每条诊断的规则依据

### 2.2 悬浮说明与依据追踪
- 用户悬浮在错误处时显示详细信息
- 显示内容：
  - 错误摘要
  - 建议修复
  - 当前组件/属性说明
  - 来源文档链接
  - 规则置信度

### 2.3 批量检查
- 支持多种检查范围：
  - 当前文件检查
  - 当前目录检查
  - 整个项目检查
- 报告导出：
  - 支持Markdown/JSON格式导出
  - 报告按error、warning、info分组
  - 报告包含文件路径、行列号、诊断code、修复建议、规则来源

## 3. 非功能需求

### 3.1 性能需求
- 单文件实时检测响应时间 ≤ 50ms
- 大文件分析响应时间在合理范围内（详见 TDD.md 性能设计）

### 3.2 兼容性需求
- 支持IntelliJ IDEA 2024.1+（Ultimate / Community Edition）

### 3.3 可用性需求
- 检测结果以IDEA标准诊断格式呈现（波浪线、侧栏标记）
- Quick Fix操作与IDEA原生Quick Fix交互一致
- 规则库易于扩展维护（详见 DSL-Rule-Spec.md）

## 4. 用户场景

场景1：开发者编辑DSL文件，输入错误标签名
→ 实时标红波浪线 → 悬浮提示"未知元素" → Quick Fix建议替换为最接近的合法标签 → 一键修正

场景2：开发者遗漏必填属性
→ 实时标黄波浪线 → 悬浮提示"缺失必填属性name" → Quick Fix自动补全 → 一键添加

场景3：团队提交前质量检查
→ 执行批量检查 → 生成项目级别错误汇总 → 批量Quick Fix修正 → 确保全部通过
