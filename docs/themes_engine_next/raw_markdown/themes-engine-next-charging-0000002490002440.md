# 充电动效换肤<ChargingSkin>

功能概述

充电动效换肤支持替换系统自带的充电效果。设计师可以通过引擎脚本的方式输出充电动效的效果，在用户充电时，系统支持触发主题引擎渲染此目录下的引擎脚本，渲染充电动效效果。

XML规范

```
<?xml version="1.0" encoding="utf-8"?>
<ChargingSkin screenWidth="1080"/>
</ChargingSkin >
```

参数说明

| **参数** | **类型** | **选项** | **注释** |
| --- | --- | --- | --- |
| screenWidth | 数值 | 选填 | 描述文件的虚拟的屏幕宽度，根据该宽度和手机屏幕的宽高比能够计算出相应的虚拟的屏幕的高度。描述文件中的数值基于该虚拟的屏幕的宽高，例如分辨率为1560*720的手机在设置screenWidth为1080的描述文件中，其#screen_width为1080,#screen_height为1920，能够保持在同一个屏幕宽高比例的手机中组件的相对位置保持不变。设定屏幕宽度标准。如果指定为720，锁屏中所有元素的位置都按720p的布局编写。1080p、480p等分辨率的手机会自动进行缩放。 |
