主题引擎DSL静态分析工具-DSL规则规范文档

1. DSL规范支持范围

1.1 文件格式
- 支持XML格式的DSL文件识别与解析
- DSL文件识别：基于文件扩展名及根元素声明双重判定

1.2 元素定义规范
每个DSL元素在规则库中需定义以下约束：
| 约束项 | 说明 |
|---|---|
| 元素名称 | 合法标签名 |
| 必填属性 | 该元素必须包含的属性列表 |
| 可选属性 | 该元素允许但非必填的属性列表 |
| 属性类型 | 各属性值的合法类型（字符串、整数、枚举、引用等） |
| 枚举值 | 枚举类型属性的合法取值集合 |
| 父元素约束 | 该元素允许出现的父级元素列表 |
| 子元素约束 | 该元素允许包含的子级元素列表 |
| 继承关系 | 该元素是否继承自其他元素，继承的属性传递规则 |

2. 错误检测类型

2.1 语法错误
| 错误类型 | 检测内容 | 示例 |
|---|---|---|
| XML标签未闭合 | 标签缺少闭合标签或自闭合标记 | `<Tag>...</Tag>` 缺少闭合 |
| 标签嵌套错误 | 元素嵌套违反父子约束 | 子元素出现在不允许的父级下 |
| 属性引号缺失 | 属性值缺少引号包裹 | `attr=value` |
| 未知元素 | 使用了规则库中未定义的标签 | `<unknownTag>` |
| 未知属性 | 使用了当前元素不支持属性 | `unknownAttr="value"` |
| 缺失必填属性 | 元素缺少必填属性 | `<tag>` 缺少 `name` 属性 |
| 属性值类型错误 | 属性值不符合声明的类型 | `count="abc"` (期望整数) |
| 枚举值错误 | 属性值不在合法枚举集合中 | `type="invalidType"` |

2.2 语义/规则错误
| 错误类型 | 检测内容 | 示例 |
|---|---|---|
| 未知组件 | 使用了规范中未定义的组件 | `<UnknownComponent>` |
| 组件不支持当前应用位置 | 组件出现在不允许的上下文中 | 子组件出现在错误的父级下 |
| 属性上下文冲突 | 同一属性在不同父级下类型/枚举值不同 | 继承场景中属性类型不兼容 |
| 单位不匹配 | 属性值使用了不合法或不适用的单位 | `margin="10pt"` (期望dp) |
| 数值范围越界 | 属性值超出合法数值范围 | `opacity="3"` (期望0~1) |
| 重复定义 | 同一ID/名称重复声明 | `id="sameId"` 出现两次 |
| 引用不存在 | 属性引用了未定义的目标 | `ref="nonExistent"` |
| 继承链断裂 | 继承声明指向不存在的父元素 | `extends="ghostElement"` |

2.3 语义相似度匹配
- 当检测到未知元素/属性时，基于编辑距离或语义相似度算法，推荐最接近的合法候选
- 优先级排序：完全匹配 > 编辑距离匹配 > 语义匹配

3. 规则来源与文档追踪

3.1 诊断附带信息
- 每条诊断信息须附带规则来源标识（规则ID）
- 每条诊断信息须附带规则文档URL，指向该规则的在线说明页面

3.2 规则来源格式
- 规则ID格式：`[类别]-[编号]`，如 `SYN-001`（语法类第1条）、`SEM-003`（语义类第3条）
- 文档URL格式：`https://dsl-docs.example.com/rules/{规则ID}`

4. 规则库维护

4.1 规则条目结构（示例）
```json
{
  "element": "Theme",
  "requiredAttrs": ["name", "version"],
  "optionalAttrs": ["author", "description"],
  "attrTypes": {
    "name": "string",
    "version": "string",
    "author": "string"
  },
  "enumValues": {},
  "allowedParents": ["ThemeRoot"],
  "allowedChildren": ["Style", "Color", "Dimension"],
  "inherits": null
}
```

4.2 扩展指南
- 新增元素：在规则库中追加元素条目，填写上述所有约束字段
- 新增属性：在对应元素条目的 optionalAttrs / attrTypes 中追加
- 新增检测规则：实现对应Analyzer并注册到检测引擎（详见 TDD.md）
